# MK Water Industries

A modern, responsive corporate website developed for **MK Water Industries**, a packaged drinking water manufacturer based in Nanded, Maharashtra.

## 🌐 Overview

The website showcases the company's products, manufacturing process, services, quality standards, and contact information with a clean, modern, and professional user interface.

## ✨ Features

- Responsive design for Mobile, Tablet, and Desktop
- Modern UI with smooth animations
- Product showcase
- About Company
- Manufacturing Process
- Quality Assurance
- Services
- Contact Form
- Google Maps Integration
- WhatsApp Chat Button
- Call Now Button
- SEO Optimized
- Fast Loading
- Vercel Ready

## 🛠 Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React Icons
